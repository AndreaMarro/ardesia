# Ardesia — Design Context (impeccable)

## Audience
Andrea (electronics teacher/tutor) and his students. Used live in class on **LIM (interactive whiteboard) and iPad**, and by students reviewing at home. Non-expert users; the interface must be immediately legible across the room and calm under a teacher's cognitive load.

## Use cases
Open the board → drop a Simulation Plugin post-it → mount/build a circuit (volume experiment *or* free-form) with pin-perfect parity → simulate real physics → break it and get the error explained → generate tutor/student materials → reopen without losing state.

## Brand personality / tone
**"Ardesioso" — a slate blackboard reimagined as a modern-art canvas.** The scholarly calm of chalk-on-slate as the ground, with **bold, confident geometric-abstract accents in the spirit of Kandinsky and Picasso**: primary hues (a true blue, a warm ochre/red, a viridian), decisive shapes, intentional asymmetry. Refined, not busy. Beautiful enough to feel like a painting, disciplined enough to teach from.

## Direction (commitments)
- **Palette**: slate/ink neutrals tinted toward a cool blue-grey (never pure #000/#fff); a small set of *decisive* Kandinsky accents (cobalt blue, ochre, viridian, a signal red for errors) used sparingly for meaning, not decoration. No cyan-on-dark / purple-blue-gradient AI slop.
- **Typography**: a distinctive display face for the wordmark/titles (NOT Inter/Roboto/system) paired with a refined, highly-legible body; strong weight/size hierarchy; generous for LIM legibility.
- **Space & rhythm**: varied spacing, intentional asymmetry, breathing room; not everything in identical cards. The circuit/board is the hero.
- **Motion**: restrained — meaningful state changes (solved glows on, error pulses once), ease-out, respects reduced-motion.
- **Signature detail**: an "ardesia" chalk-edge / slate texture and a single Kandinsky geometric mark as the brand accent — the thing someone remembers.
- **Accessibility**: AA contrast, LIM/iPad touch targets, keyboard + reduced-motion.

## Constraints
React + Vite (studio app), Excalidraw board host, existing `--m-*` design tokens (theme file). Refine tokens/chrome; do NOT churn the sim-canvas React callbacks (a concurrent session owns them). Every change verified: tsc + tests + live screenshot.

## Artist language (UI/UX vocabulary)
The ardesioso canvas speaks through modern masters — each maps to a concrete UI move, used sparingly:
- **Lucio Fontana** (Concetto Spaziale, *tagli*): ONE decisive diagonal **cut** as a signature gesture — section accents, reveals. Never busy.
- **Alexander Calder** (mobiles): balanced **primary discs on a thin wire**, gently **kinetic** — the brand mark; reduced-motion safe.
- **Joan Miró**: playful **primary marks + black line** (star, eye, biomorph) — empty states, delight moments.
- **Alberto Burri** (*cretti/sacchi*): raw **slate/matter texture** — subtle board/surface grain (the "ardesia" itself).
- **Keith Haring**: bold **outline + radiant lines**, pop energy — success/celebration (circuit solved → radiant pulse).
Palette = slate neutrals + a small primary set (cobalt blue, ochre, viridian). Motion = restrained, meaningful, ease-out.

## The test
Someone should ask "how was this made?" — never "which AI made this?" Slate + Calder + Fontana, taught with love.

Registry SRI was checked against downloaded archives; no manifest or lock change. No donor was executed to repair/configure REA. Upstream surfaces inspected: PDFViewer constructor/version guard, rendering queue, page-change events, FindController dispatch, LinkService destinations, text layer DOM; OSD shipped viewport/tile implementation and complete license preface; BlockNoteEditor/schema/insertBlocks; Annotorious W3C fragment/SVG parser. Full source code remains upstream and/or in the existing installed locked package, unmodified; reproducible hashes identify the precise inspected files. Candidate tarballs are scratch in work/upstream, not shipped dependencies.

Worker/assets/security: PDF parsing happens in a dedicated module worker from this origin. Full viewer annotations/forms/autolinks and annotation editors are disabled, no scripting manager/XFA is supplied. PDF.js 6.4.299 no longer exposes isEvalSupported and its shipped main module contains no eval call; testing uses CSP without unsafe-eval. MathLive output uses the existing DOMPurify boundary. Only inert native text, rectangles and sanitized MathLive previews enter the DOM. Original PDF remains a download, never object/iframe/embed.

Memory: source upload remains Core's existing 20 MiB / 20 page bound. Viewer canvas cap 8M pixels, decode area hint 16 MiB, thumbnails ~96 px wide. These are allocation hints, not process memory limits; worker/browser may allocate more. Rendering queue manages visible pages, but all small thumbnails are currently rendered. Worker, page/text layers, blob URLs, listeners and observer are torn down when source/session changes. No localStorage personal archive. Runtime is loaded lazily and the worker is shared as a module asset with the existing notebook path, never as a second package instance.

Attribution is visible in the reader and links to the installed same-origin LICENSE. pdfAssets distributes the original license and dependency data-file notices already supported on main. No upstream NOTICE file is present in the installed package; PDFJS-LICENSE is an unmodified copy. The local source fixture is original test material, not a licensed textbook and not a scientific approval of course content.

# Controllo della cronologia delle prime prove

Le prime cinque prove oracolo erano già state eseguite sul testo leggibile finale delle note. Un successivo controllo ha ipotizzato erroneamente una precedente edizione delle note e ricostruito il loro primo WIP: l’assert di uguaglianza hash è fallito (exit 1), correttamente. La ricostruzione non è il modulo che ha prodotto i report e non è mai stata eseguita come oracolo.

Il controllo dei byte ha poi confermato che il dependencySHA dei primi report coincide esattamente con il modulo corrente, copiato qui come actual-evidence-matching-report.py.snapshot. I primi report e il loro terminale restano immutati. La ripetizione reale del generatore viene conservata separatamente, senza attribuire una nuova revisione scientifica o un cambio di modello a una duplicazione identica.

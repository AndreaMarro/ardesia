# Fonte e figure lette dall’autore C4 A

Letti individualmente i soli cinquanta enunciati C4-Q001..050 prima di scrivere i cinquanta nuovi svolgimenti. Riletti integralmente testo e formule delle cinque lezioni C4-L01..05 e i quattordici SVG originali in XML. Questi snapshot conservano i byte del pin e la provenienza. Il file C4 originale è un archivio integrale: non implica che le chiavi della metà B siano state aperte. Primaria o modello B dei quesiti A e candidati B C4 non sono stati aperti durante l’autoria.

È una ricevuta d’autore e di lettura delle fonti, non una primaria blind di peer review né una verifica scientifica propria. Le figure nuove vengono lette separatamente nei rispettivi PNG nativi completi. Nessun collaudo UI del prodotto o approvazione umana è dichiarato.

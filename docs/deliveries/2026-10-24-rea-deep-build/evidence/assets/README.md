# Audio dimostrativo: provenienza e correzione esplicita

Testo originale Ardesia in `bin/web/poiseuille-demo.json`; WAV mono PCM22050/16bit generato offline con il comando `node bin/web/generate_poiseuille_voice.mjs /absolute/local/@echogarden/espeak-ng-emscripten/espeak-ng.js`. Tool fissato a0.3.5, voce formante `it`, rate0.95. Nessuna voce MBROLA, registrazione umana o modello vocale esterno; nessuna API o microfono fisico. SHA/durata/bytes nel JSON adiacente. Player manuale, preloadnone, testo completo sempre leggibile. Il WAV opzionale pesa1.81MB: costo della riproduzione distinto dal carico iniziale; voce sintetica meno naturale di una spiegazione del docente.

**Correzione datata24 ottobre:** la fixture iniziale era stata generata con `say` e voce di sistema macOS. La verifica dei diritti ha rilevato la restrizione a contenuti personali non commerciali, quindi quella fixture è stata esclusa da codice, build e consegna pubblicabile prima del commit. Copia rifiutata resta solo nel workspace privato per tracciabilità; le precedenti prove di playback non attestano il nuovo file. Nuova proiezione SHA e nuova prova browser sono richieste dopo la sostituzione.

Qui distribuiamo la sintesi del nostro testo originale, senza distribuire engine, `.data`, codice o asset di quel tool nel prodotto. Nessuna nuova dipendenza di esecuzione o modifica del lock Ardesia. La toolchain locale è conservata in work con package-lock; la generazione non è richiesta per avviare l'app, che usa il WAV versionato.

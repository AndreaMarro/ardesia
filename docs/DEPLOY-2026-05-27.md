# Deploy 2026-05-27 — Browser-Native Compile + Upload

## Cosa è stato fatto

End-to-end browser-native cross-compile + upload per Arduino Nano R4 + ATmega328P boards. Implementato in questa session da Andrea:

1. **Board registry** (`src/services/arduinoBoards.js`) — 11 modelli Arduino canonical
2. **In-browser AVR compiler** (`src/services/inBrowserAvrCompiler.js`) — emette ATmega328P machine code da Arduino C++ senza backend
3. **WebSerial stk500 service** (`src/services/webSerialFlash.js`) — upload reale Arduino Nano/Uno AVR
4. **Universal upload dispatcher** (`src/services/arduinoUploader.js`) — routing per protocollo (stk500/DFU/BOSSA/esptool)
5. **UI components** — `BoardPicker`, `UniversalUploadButton`, `R4DfuUploadButton`, `WebSerialUploadButton`, `HomeUnlimChatInline`
6. **Precompiled HEX** — `v3-cap6-esp3` + `v3-cap6-esp4` per AVR + Renesas R4
7. **Supabase compile-proxy patched** — forward `fqbn` per cloud R4 compile (richiede redeploy)
8. **HomeCompileEntry + NewElabSimulator** — wired con BoardPicker + UniversalUploadButton

## Deploy steps (Andrea esegue)

### 1. Deploy Supabase Edge Function compile-proxy

Necessario per attivare il forward del FQBN al backend n8n. Senza questo, compile per Nano R4 fallisce attraverso il canale online (i precompiled HEX continuano funzionare).

```bash
cd "/Users/andreamarro/VOLUME 3/PRODOTTO/elab-builder"
SUPABASE_ACCESS_TOKEN=sbp_xxx npx supabase functions deploy compile-proxy \
  --project-ref euqpdueopmlllqjmqnyb
```

Verifica deploy:
```bash
curl -X POST -sS -H "Content-Type: application/json" \
  -d '{"code":"void setup(){pinMode(13,OUTPUT);}void loop(){digitalWrite(13,HIGH);delay(500);}","fqbn":"arduino:renesas_uno:nanor4"}' \
  https://euqpdueopmlllqjmqnyb.supabase.co/functions/v1/compile-proxy | head -c 200
```

Risposta attesa: `{"success":true,"hex":"..."}` (n8n potrebbe ancora ignorare fqbn fino al suo upgrade — vedi step 2).

### 2. Upgrade n8n /webhook/compile (opzionale ma raccomandato)

n8n attualmente ha solo AVR core. Per supportare Renesas R4 cross-compile online:

```bash
# SSH sul VPS n8n (srv1022317.hstgr.cloud)
arduino-cli core install arduino:renesas_uno
```

E aggiornare il workflow n8n per:
- Accettare campo `fqbn` dal body
- Passarlo a `arduino-cli compile --fqbn $fqbn`

Senza questo step, R4 online compile continua restituire AVR HEX (precompiled HEX esp3/esp4 funzionano comunque).

### 5. Hardware UAT (Riccardo Omaric)

Collegare Nano R4 fisica via USB:
- Aprire #compile-home
- Selezionare "Arduino Nano R4" (default)
- Premere "Compila" → atteso "success" verde
- Premere "Carica su Arduino Nano R4"
- Browser apre prompt USB device picker → selezionare Nano R4 (modalità DFU: doppio click reset)

Collegare Nano AVR (ATmega328P):
- Selezionare "Arduino Nano (ATmega328P, old bootloader)"
- "Compila" → in-browser AVR compiler emette HEX immediatamente
- "Carica" → WebSerial prompt → selezionare porta seriale → stk500v1 flash

## Browser support

- **Chrome / Edge / Opera**: WebUSB + WebSerial supportati → full functionality
- **Safari**: WebSerial + WebUSB NON supportati → bottoni mostrano "non disponibile" con messaggio plurale. Fallback: usa Chrome.
- **Firefox**: WebSerial dietro flag, WebUSB non supportato → uso non raccomandato per upload.

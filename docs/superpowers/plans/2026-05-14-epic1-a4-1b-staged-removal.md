## NON COMPIACERE — honest caveats (read before starting)

1. **This A4.1b is larger than the iter-55 activation §4 roadmap implied.** Recon found the 13 ids are live experiment *definitions* in `experiments-vol3.js` + the `capitoli/` layer, which the roadmap omitted. Full removal is required for parità stretta; the narrow scope would ship phantom experiments.
2. **The test-count floor moves down.** Deleting 13 experiment definitions deletes their per-experiment *generated* tests. Task 3 re-baselines `automa/baseline-tests.txt` with an arithmetic proof (`post = pre − Δgenerated`). This is an owner-delegated deliberate re-baseline, not a silent weaken. The proof must be produced, not asserted. If the drop exceeds Δgenerated by even one test → a real regression → REVERT.
3. **The removal cannot be sub-split into more than 2 commits.** Any intermediate state between "lesson-paths deleted" and "all references updated" has red tests. Task 3 is therefore one large task → one atomic commit. Its *steps* are bite-sized; its *commit* is single.
4. **Deferred to A4.1d (not fixed here):** the surviving lesson-paths whose `next_experiment.id` points at a removed id. Task 1 confirms the exact dangling set; Task 3 records it in the manifest; it is NOT re-threaded.
5. **`public/hex/*.hex`** artifacts for some removed ids are outside `src/`. Task 1 lists them; Task 3 removes them (a hex with no experiment is dead weight) unless Task 1 surfaces a reason not to.

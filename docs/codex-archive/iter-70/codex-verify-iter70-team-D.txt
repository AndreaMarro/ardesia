# Verification Before Completion

## Overview

Claiming work is complete without verification is dishonesty, not efficiency.

**Core principle:** Evidence before claims, always.

**Violating the letter of this rule is violating the spirit of this rule.**

## The Iron Law

```
NO COMPLETION CLAIMS WITHOUT FRESH VERIFICATION EVIDENCE
```

If you haven't run the verification command in this message, you cannot claim it passes.

## The Gate Function

```
BEFORE claiming any status or expressing satisfaction:

1. IDENTIFY: What command proves this claim?
2. RUN: Execute the FULL command (fresh, complete)
3. READ: Full output, check exit code, count failures
4. VERIFY: Does output confirm the claim?
   - If NO: State actual status with evidence
   - If YES: State claim WITH evidence
5. ONLY THEN: Make the claim

Skip any step = lying, not verifying
```

## Common Failures

| Claim | Requires | Not Sufficient |
|-------|----------|----------------|
| Tests pass | Test command output: 0 failures | Previous run, "should pass" |
| Linter clean | Linter output: 0 errors | Partial check, extrapolation |
| Build succeeds | Build command: exit 0 | Linter passing, logs look good |
| Bug fixed | Test original symptom: passes | Code changed, assumed fixed |
| Regression test works | Red-green cycle verified | Test passes once |
| Agent completed | VCS diff shows changes | Agent reports "success" |
| Requirements met | Line-by-line checklist | Tests passing |

## Red Flags - STOP

- Using "should", "probably", "seems to"
- Expressing satisfaction before verification ("Great!", "Perfect!", "Done!", etc.)
- About to commit/push/PR without verification
- Trusting agent success reports
- Relying on partial verification
- Thinking "just this once"
- Tired and wanting work over
- **ANY wording implying success without having run verification**

## Rationalization Prevention

| Excuse | Reality |
|--------|---------|
| "Should work now" | RUN the verification |
| "I'm confident" | Confidence ≠ evidence |
| "Just this once" | No exceptions |
| "Linter passed" | Linter ≠ compiler |
| "Agent said success" | Verify independently |
| "I'm tired" | Exhaustion ≠ excuse |
| "Partial check is enough" | Partial proves nothing |
| "Different words so rule doesn't apply" | Spirit over letter |

## Key Patterns

**Tests:**
```
✅ [Run test command] [See: 34/34 pass] "All tests pass"
❌ "Should pass now" / "Looks correct"
```

**Regression tests (TDD Red-Green):**
```
✅ Write → Run (pass) → Revert fix → Run (MUST FAIL) → Restore → Run (pass)
❌ "I've written a regression test" (without red-green verification)
```

**Build:**
```
✅ [Run build] [See: exit 0] "Build passes"
❌ "Linter passed" (linter doesn't check compilation)
```

**Requirements:**
```
✅ Re-read plan → Create checklist → Verify each → Report gaps or completion
❌ "Tests pass, phase complete"
```

**Agent delegation:**
```
✅ Agent reports success → Check VCS diff → Verify changes → Report actual state
❌ Trust agent report
```

    43	/**
    44	 * Group terms by initial letter (uppercase, dedup punctuation).
    45	 * Returns sorted alphabet list and a map letter → terms[].
    46	 */
    47	export function indexByLetter(terms) {
    48	  const map = new Map();
    49	  for (const t of terms) {
    50	    const ch = (t.term || '').trim().charAt(0).toUpperCase();
    51	    if (!ch) continue;
    52	    if (!map.has(ch)) map.set(ch, []);
    53	    map.get(ch).push(t);
    54	  }
    55	  return {
    56	    letters: Array.from(map.keys()).sort((a, b) => a.localeCompare(b, 'it')),
    57	    byLetter: map,
    58	  };
    59	}

    61	/**
    62	 * Filter terms by volume set + free-text search.
    63	 * Returns new array (preserves original order within filter).
    64	 */
    65	export function filterTerms(allTerms, { volumes, search }) {
    66	  const set = new Set(volumes && volumes.length ? volumes : ALL_VOLUMES);
    67	  const q = (search || '').trim().toLowerCase();
    68	  return allTerms.filter((t) => {
    69	    if (!set.has(t.volume)) return false;
    70	    if (!q) return true;
    71	    const hay = `${t.term} ${t.tecnico} ${t.bambini} ${t.capitoloTitle}`.toLowerCase();
    72	    return hay.includes(q);
    73	  });
    74	}

   445	  const start = Math.max(0, Math.floor(scrollTop / rowHeight) - overscan);

    75	/**
    76	 * Lightweight runtime validator for fumetto payload.
    77	 * Returns: { valid: boolean, errors: string[], warnings: string[] }
    78	 */
    79	export function validateFumettoPayload(payload) {
    80	  const errors = [];
    81	  const warnings = [];
    82	
    83	  if (!payload || typeof payload !== 'object') {
    84	    errors.push('Payload must be a non-null object');
    85	    return { valid: false, errors, warnings };
    86	  }
    87	
    88	  // experimentId
    89	  if (!isValidExperimentId(payload.experimentId)) {
    90	    errors.push(
    91	      `experimentId "${payload.experimentId}" must match v[1-3]-cap<n>-esp<n>`
    92	    );
    93	  }
    94	
    95	  // session (required object)
    96	  if (!payload.session || typeof payload.session !== 'object') {
    97	    errors.push('session is required');
    98	  } else {
    99	    const sReq = ['classKey', 'anonStudentId', 'startedAt', 'completedAt', 'durationSec'];
   100	    for (const k of sReq) {
   101	      if (payload.session[k] === undefined || payload.session[k] === null) {
   102	        errors.push(`session.${k} is required`);
   103	      }
   104	    }
   105	    if (
   106	      payload.session.ageBand &&
   107	      !FUMETTO_ENUMS.ageBands.includes(payload.session.ageBand)
   108	    ) {
   109	      errors.push(`session.ageBand "${payload.session.ageBand}" not in enum`);
   110	    }
   111	  }
   112	
   113	  // panels (required array, 4-6)
   114	  if (!Array.isArray(payload.panels)) {
   115	    errors.push('panels must be an array');
   116	  } else {
   117	    if (payload.panels.length < MIN_PANELS || payload.panels.length > MAX_PANELS) {
   118	      errors.push(
   119	        `panels.length must be between ${MIN_PANELS} and ${MAX_PANELS} (got ${payload.panels.length})`
   120	      );
   121	    }
   122	    payload.panels.forEach((p, i) => {
   123	      const ctx = `panels[${i}]`;
   124	      if (!FUMETTO_ENUMS.panelRoles.includes(p.role)) {
   125	        errors.push(`${ctx}.role "${p.role}" not in enum`);
   126	      }
   127	      if (p.tagColor && !FUMETTO_ENUMS.tagColors.includes(p.tagColor)) {
   128	        errors.push(`${ctx}.tagColor "${p.tagColor}" not in enum`);
   129	      }
   130	      if (typeof p.index !== 'number' || p.index < 1 || p.index > MAX_PANELS) {
   131	        errors.push(`${ctx}.index must be integer 1-${MAX_PANELS}`);
   132	      }
   133	      if (Array.isArray(p.balloons)) {
   134	        p.balloons.forEach((b, j) => {
   135	          const bctx = `${ctx}.balloons[${j}]`;
   136	          if (!FUMETTO_ENUMS.speakers.includes(b.speaker)) {
   137	            errors.push(`${bctx}.speaker "${b.speaker}" not in enum`);
   138	          }
   139	          const wc = countWords(b.text);
   140	          if (wc > WORD_LIMIT_PER_BALLOON) {
   141	            errors.push(
   142	              `${bctx} exceeds ${WORD_LIMIT_PER_BALLOON} word limit (got ${wc})`
   143	            );
   144	          }
   145	          if (typeof b.wordCount === 'number' && b.wordCount !== wc) {
   146	            warnings.push(
   147	              `${bctx}.wordCount claimed ${b.wordCount} but actual is ${wc}`
   148	            );
   149	          }
   150	        });
   151	      }
   152	    });
   153	  }
   154	
   155	  // principioZero (required object)
   156	  if (!payload.principioZero || typeof payload.principioZero !== 'object') {
   157	    errors.push('principioZero is required');
   158	  } else if (typeof payload.principioZero.score === 'number') {
   159	    if (
   160	      payload.principioZero.score < 0 ||
   161	      payload.principioZero.score > 100
   162	    ) {
   163	      errors.push('principioZero.score must be in 0-100');
   164	    }
   165	  }
   166	
   167	  // rendering
   168	  if (!payload.rendering || typeof payload.rendering !== 'object') {
   169	    errors.push('rendering is required');
   170	  } else {
   171	    if (
   172	      payload.rendering.format &&
   173	      !FUMETTO_ENUMS.renderFormats.includes(payload.rendering.format)
   174	    ) {
   175	      errors.push(`rendering.format "${payload.rendering.format}" not in enum`);
   176	    }
   177	    if (
   178	      payload.rendering.size &&
   179	      !FUMETTO_ENUMS.renderSizes.includes(payload.rendering.size)
   180	    ) {
   181	      errors.push(`rendering.size "${payload.rendering.size}" not in enum`);
   182	    }
   183	  }
   184	
   185	  return { valid: errors.length === 0, errors, warnings };
   186	}

## 6. Architettura raccomandata (intelligenza preservata + sostenibile)

Principio: **intelligenza efficace ≈ qualità-modello × struttura-di-verifica.** L'intelligenza percepita viene dalle poche decisioni dure, non dal volume (opus-su-ogni-tick è ciò che si è rotto).

- **Lane A — grind continuo, ~0 budget Anthropic:** swarm low-cost (DeepSeek V4-Flash $0.14/$0.28; Kimi K2.6; DeepSeek V4-Pro; Qwen3-Coder; GLM-5.1) in parallelo = best-of-N + review incrociata. API proprie, fuori dal credito Anthropic. È il `ROUTE_BUILDER` di default corretto (inverte "builder=opus").
- **Lane B — burst opus event-driven (metered, cached):** opus-4-8 `effort high/xhigh` SOLO per architettura, escalation dure, review adversariale, firma gate. Cache TTL-1h (~10× sconto — **bug aperto: oggi TTL-5min scade tra i tick a 300s → ogni tick paga il prefisso pieno**). Cost-gate in $ (sommare `total_cost_usd` da `--output-format json`), stop prima del cap.
- **Lane C — TUI interattiva (pool Max, 0€):** ragionamento profondo + ratifica pin lo fai TU in sessione interattiva, ancora coperta dal piano.

**Decisione robusta (raccomandata dagli agenti):** spostare il loop autonomo non presidiato da token OAuth a una **`ANTHROPIC_API_KEY` dedicata (Commercial Terms)** — niente downgrade silenzioso, niente cap subscription, billing prevedibile, niente ambiguità ToS (precedente ban OpenClaw 02/2026 per credenziali subscription in tool terzi). Token OAuth solo per interattivo presidiato. Onestà: questo NON è "solo i piani" — ma "solo i piani" per un loop 24/7 è ormai un vicolo cieco (capped + ToS-grigio + downgrade). Plan-only resta valido per Lane C.
